# 锈雨 · RUSTFALL

> 酸雨会洗掉一切，除了还在走的东西。

**Vue 3 + Three.js** 的废土像素横版生存游戏。你是一台还能走的锈蚀机器人，在七个废墟区域之间
捡零件、修中继、撬牢笼、捡枪，赶在酸雨落下之前攒够电量待机。

所有像素美术、立绘、天空/天气、粒子、音效都在运行时由代码生成，**无任何外部图片/字体/音频素材**。

- 7 个区域 · **120 间房**（上一版 24 → **5×**）
- 4 种大型敌人 + 8 种普通敌人 + 4 类生态生物
- 12 把武器 / 6 种弹药（部分机体无法装配）
- 日夜循环（6 时段）+ 7 种天气 + 酸雨季
- 支持 Xbox / 标准手柄；画面特效可开关（后期与光晕默认关闭）
- 代码量：**63,906 行 / 115 个文件**（上一版 47,386 / 92）
- 51 个可交互道具（新增通风管/病床/担架/灯塔/缆盘等 18 种）、7 套生态背景（含地铁/医院/港口）

## 运行

```bash
npm install
npm run dev        # 开发服务器（scripts/dev-server.mjs，默认 5180）
npm run build      # 生产构建
npm run preview    # 静态预览（4180）
```

需要一个 WebGL2 浏览器。

### 日夜与天气

一天 = 一个循环（300 秒），6 个时段：黎明 → 清晨 → 正午 → 午后 → 黄昏 → 夜晚。
环境亮度、色温、云层、星野、日月、背景视差都会跟着变；夜晚明显更暗更冷。

7 种天气按生态权重轮换：晴 / 阴 / 落灰 / 沙暴 / 酸雨 / 毒雾 / 辐射风暴。
每种天气有自己的雾、风、雨量、染色、能见度和音色；循环末段强制转入酸雨季——
这是唯一会致死、也是逼你回避难所的天气。HUD 右上角显示天数、时段、24h 时钟、天气、风力与温度。

### 生存循环

倒计时归零 → 酸雨；暴露 5 秒报废（同时持续掉血）。攒够 3 格电量回房按住 `↓` 待机 → 信号 +1，
进入下一天；电量不足则信号 −1。死亡在最近避难所重启，信号 −1。

## 这一轮新增/修复（对应 11 条要求）

1. **机体卡片重叠**：卡片网格改为内容撑高（`grid-auto-rows: max-content`）+ 溢出裁剪，
   9 张卡（含 mod 机体）实测 0 重叠、0 内容溢出。
2. **消除贴图透明边**：新增 `render/materials.js`（alpha 二值化 + `alphaTest`），并对 art 层
   597 张贴图做统一二值化（a<200→0，a≥200→255）——描边不再是半透明灰边，光晕只落在不透明像素上。
   角色、怪物、道具、战利品、生态、武器全部走同一材质入口。
3. **完整动作**：每台机体 14 组动画共 43 帧：
   `idle[4] run[8] jump[2] fall[2] land[2] crouch[2] climb[4] swim[4] dig[3] attack[3] shoot[2] hold[2] hurt[2] dead[3]`；
   状态机按 受伤 > 开枪 > 攻击 > 挖掘 > 游泳/攀爬 > 空中 > 落地 > 蹲 > 跑 > 持枪待机 > idle 决策，
   带缺帧回退链、落地压缩、持枪网格与后坐。
4. **画面效果可选项，默认关闭**：设置面板（`F2`）可开关 **后期滤镜 / 光晕 Bloom / 扫描线 / 噪点 / 暗角 / 时钟**；
   `postfx` 与 `glow` **默认关**，关掉后直接渲染，帧率更稳；设置写回存档与 localStorage。
5. **日夜 + 天气循环系统**：`systems/daynight.js`（时段/天气状态机、权重、预报、闪电、酸雨季）+
   天空/云/星/日月/天气幕渲染（`art/world.js`、`atmosphere.js`）+ postfx 的 ambient/night/weatherTint/
   fog/wetness 五个新 uniform + 音频环境层（`audio.setAmbience`）。
6. **地形不再单一**：每房保证 ≥3 层可站立面、2 个竖向通道、隐藏壁龛；新增裂墙/泥土/酸液/水/爬杆、
   塌方堆、断桥、通风管、天花板吊挂、单向平台迷宫；道具新增 12 种。
7. **Xbox 手柄**：`input.js` 完整标准布局（左右摇杆 + 扳机 + 全部按键、死区/重复/震动、热插拔），
   HUD 连接提示，设置里可调死区与关闭震动。实测模拟手柄：移动/跳跃/攻击/交互/瞄准全部命中。
8. **大型敌人**：4 种，随机分布在房间（shelter 不刷，同场最多 2 只）：
   - `junk_golem` 废弃垃圾组合型：拆自己部件投掷、打断腿后趴下可处决、死亡炸出零件
   - `sky_warden` 飞行控制型：召唤无人机、扫射激光、半血过载
   - `mimic_beast` 动物拟态形：伪装成车骸/尸体/垃圾堆，靠近现形
   - `swarm_core` 群聚组合型：持续产爬虫，清空小怪才暴露核心
9. **生态系统**：`ecosystem/`——

   - 植物拟态：无害非智能体，随风摆动、可采集纤维/种荚
   - 苍蝇 / 老鼠：环境生物，躲避玩家
10. **武器散落**：12 把（激光手枪/步枪、半自动手枪、导轨钉、钉枪、废料发射器、电弧发射器、
    铁棍、匕首、榔头、重型扳手、电击棒），6 种弹药；按机体 `carry/hitbox/能力` 判定兼容，
    不兼容给中文原因（例：「这条机械臂握不住重锤」）。房间掉落 + 弹药配对，HUD 显示弹匣/备弹/换弹。
11. **5× 内容**：24 → **120 间房**（7 区域）、更大的房型、更多敌人/武器/生态/道具，

## 已知取舍

- 后期与光晕默认关闭（按需求），想要「胶片感」在设置里打开；扫描线/噪点同理。
- 大型敌人同场最多 2 只，避免小房间堆怪；「群聚组合型」的小怪上限为 8。
- 武器命中由武器系统自己结算（避免引擎对玩家/怪物重复扣血），引擎侧投射物只负责飞行与视觉。
- 全部美术为程序化生成；风格统一，但细节密度不如手绘。
- 存档在 localStorage：`rustfall.save.v1` / 地形 `rustfall.terrain.v1` / 设置 `rustfall.settings.v1`。
