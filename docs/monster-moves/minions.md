## 一、通用规则（BaseMonster）

| 项目 | 规则 |
|---|---|
| 攻击冷却 | 初始为 `0.8 + rand*0.8` 秒；`attackCd` 每帧递减。`tryAttack()` 成功后写入 `def.attackCooldown ?? 1.6` |
| 出招闸门 | 必须同时满足 `attackCd <= 0` 与 `canReachPlayer()`：欧氏距离 ≤ `attackRange`，且垂直差 `dy < max(60, h*0.9)`（`h` 为怪物身高） |
| 默认招式 | 子类不重写时 `performAttack()` 即 `hitPlayer(damage)`，**没有前摇**：判定与 `attack` 动画同帧发生 |
| 玩家受击 | `p.invuln > 0` 时不结算；命中后 `robot.applyDamage` 使 `invuln = 0.55s`，按护甲减免并 `emit PLAYER_HURT`；`hitPlayer` 命中后还会再 emit 一次（见文末 bug 清单） |
| 受击反馈 | 扣血、`hurtT = 0.18s`、水平击退 ±120、垂直 -140、血条显示 2.2s；`hp <= 0` 触发死亡 |
| 受击与状态机 | `stateT` 在受击前照常累加，`hurtT` 只让子类「暂停移动 0.18s」，**不会重置已进入的前摇计时**；因此伤害无法取消 radboar / sentry 等自定义前摇（Hulkbot 冲锋甚至完全无视硬直） |
| 死亡 | `alive = false`、`deadT` 计时，1.6s 后隐藏；按 `loot` 的概率/数量 `dropLoot`，并调用 `game.onMonsterKilled` |
| 默认 AI | 距离 < `aggro` 且有视线 → 面向玩家、以 `speed` 追击并 `tryAttack`；否则以 `speed*0.45` 巡逻，遇墙或悬崖转向 |
| 仇恨判定 | 距离与视线（`hasLineOfSight`，每 20px 采样一次瓦片）必须同时成立；脱离后多数子类不会立刻丢失目标 |
| 物理 | 地面单位：水平速度向 `vxTarget` 插值并 clamp 到 ±280，重力 `def.gravity ?? 2000`，下落速度上限 980；飞行单位不走瓦片/重力物理 |
| 飞行体 | `flying: true` 时基类只对 `body.vx` 做插值，**不积分位置**；必须像 `wingrat` / `drone` 那样自行改 `body.x/y` 才会动（否则只能靠瞬移位移） |
| 更新步长 | `director` 把每帧 `dt` clamp 到 0.05s 再调用 `monster.update`，同时异常会被捕获并打印 |

## 三、基础小怪（8）

### 3.1 辐射野猪 RADBOAR · `radboar`

**面板**：HP 60 / 速度 70 / 伤害 22 / 体型 64×42 / 攻击距离 96 / 攻击冷却 2.4s / 仇恨 380 / XP 12 / biome village、city / 特殊 `attackType: lunge`、`gravity: 2000`、`sound: growl`

**招式**

| 招式 | 触发条件 | 前摇/过程 | 判定与伤害 | 冷却/后续 |
|---|---|---|---|---|
| 蓄力冲锋 | 追击中距离 < 300、垂直差 < 130、`attackCd <= 0` | 前摇 0.5s：脚下黄圈脉动、身体后坐 `vxTarget = -facing*14`、低吼；0.5s 结束时锁定方向（玩家水平位移 > 4 则朝玩家，否则沿当前 facing），播放 run | 冲锋最长 1.15s，`vxTarget = chargeDir*268`（受基类 ±280 限制）；身体矩形与玩家矩形重叠时结算一次 22 点伤害，震屏 0.28 | 冲锋结束写入 `attackCd = 2.4`，转入 0.6s 疲劳（`vxTarget = chargeDir*18`，0.25s 后才转身）；撞墙则改为 1.2s 眩晕 |
| 撞墙自晕（结算分支） | 冲锋期间 `body.wallDir != 0` | 立即停下，回弹 `vx = -chargeDir*40`，尘土 20 粒、震屏 0.35 | 无伤害 | `stunT = 1.2`，全程 `vxTarget = 0`，是唯一稳定输出窗口 |
| 察觉威吓 | 巡逻时发现玩家 | 0.3s 站定面向玩家、黄圈淡出 0.28、growl | 无伤害 | 之后进入追击 |
| 逼近 | 追击中距离 > 116（`attackRange + 20`） | 以 70 速度正面推进；前方是墙/悬崖则停下 | 无伤害 | 距离 ≤ 116 时原地站住，等冲锋冷却 |

**行为特点 / 弱点**：全程只有冲锋能造成伤害，贴身反而不会咬人，近战职业可以直接贴脸打。
冲锋方向在蓄力结束瞬间锁死，侧向一步即可躲过；蓄力圈是最明确的前摇提示。
撞墙后自晕 1.2s，是最大破绽；蓄力时受击只会暂停 0.18s，蓄力计时照常走完，无法靠伤害取消冲锋。
`attackCd` 只在「完整冲满 1.15s」时写入；撞墙自晕后冷却往往已归零，可立刻再次蓄力（源码 bug：撞墙没有额外惩罚）。
冲锋期间受击只被硬直 0.18s，冲锋状态与计时都不会中断，伤害不能真正打断冲锋。

### 3.2 群居爬虫 CRAWLER · `crawler`

**面板**：HP 22 / 速度 132 / 伤害 8 / 体型 26×18 / 攻击距离 36 / 攻击冷却 0.75s / 仇恨 300 / XP 4 / biome city、dump、factory / 特殊 `pack: [3, 5]`、`attackType: swarm`

**招式**

| 招式 | 触发条件 | 前摇/过程 | 判定与伤害 | 冷却/后续 |
|---|---|---|---|---|
| 扑咬 | 距离 ≤ 42（`attackRange+6`）先停步，或在包夹途中 `attackCd <= 0` 且距离 ≤ 52 | 无前摇（`tryAttack` 同帧结算），播放 attack；命中帧自身前扑 `body.vx = facing*200` | 距离 ≤ 36 且垂直差 < max(60, 16.2)=60 时结算 8 点伤害 | 冷却 0.75s；命中后继续贴身以 0.4 倍速前压 |
| 包夹绕行 | 看见玩家但不在扑咬距离 | 每只随机 `orbitSide`（±1）与 `orbitR`（30~70），每 1.4~3.0s 换边；目标点 = 玩家 ±(orbitR + sin 摆动 12)，垂直 -orbitR*0.22+6 | 无伤害 | 距离 < 26 时反向后撤半步（0.6 倍速），避免叠在玩家体内 |
| 高处短跳 | 玩家中心高出自身 > 26px、距离 < 132、在地面、`hopCd <= 0` | 立即 `vy = -330`，尘土 4 粒 | 无伤害（只解决高度差） | `hopCd = 1.25` |
| 溃散惊慌 | 同伴在 300px 内死亡（同族在线表 `LIVING`） | 立即背向玩家，`attackCd = 1.2`；逃跑速度 1.5 倍（198），遇墙先试跳 `-297`（`hopCd` 1.1），不行再掉头 | 无伤害，背部泛红提示「暂时不打你」 | 持续 2.4s，之后回到待机/追击 |

**行为特点 / 弱点**：单体很弱（22 HP / 8 伤害），威胁来自 3~5 只同时包夹，逼迫玩家移动而不是站桩。
杀死任意一只会让周围 300px 内的同伴溃散 2.4s，可用来打断围攻节奏。
仇恨 300、视线判定严格，隔墙不会追；攻击距离只有 36，长武器可以在它扑上来前清掉。
血量低但速度 132，逃跑/绕后时不容易甩掉。

|---|---|---|---|---|

最怕贴脸：150px 内它会后退或后跳，后跳有 1.8s 冷却，追进死角可直接打死。
酸池伤害无视朝向、可叠加，不要站在刚落点的位置继续输出。
蓄力 0.45s 时喉囊发光，可据此提前离开落点；受击只暂停 0.18s，蓄力计时不会重置，所以打它并不能阻止它开喷。

### 3.4 翼鼠 WINGRAT · `wingrat`

**面板**：HP 34 / 速度 150 / 伤害 10 / 体型 30×24 / 攻击距离 60 / 攻击冷却 2.1s / 仇恨 360 / XP 8 / biome factory、dump、city / 特殊 `flying: true`、`hover: 150`、`gravity: 0`、`attackType: dive`

**招式**

| 招式 | 触发条件 | 前摇/过程 | 判定与伤害 | 冷却/后续 |
|---|---|---|---|---|
| 绕圈盘旋 | 发现玩家后进入 `circle` | 以 2.1 rad/s 绕玩家转，半径 130~180；目标高度 = 玩家中心 -105 + sin(角*1.7)*26 | 无伤害 | 持续 1.0~1.9s（每次随机）后进入俯冲前摇 |
| 俯冲前摇 | 绕圈计时结束 | 0.35s：收翅（翼缩放 0.35）、原地缓慢上抬、红光亮起并脉动、growl | 无伤害 | 结束时把俯冲目标锁定为玩家当前位置 |
| 俯冲撕咬 | 前摇结束 | 以 470 速度直线飞向锁定点，播放 attack，翅完全收拢 | 身体矩形与玩家矩形重叠时结算一次 10 点伤害，震屏 0.12 | 冲过目标 12px、撞墙、或持续 0.5s 后进入拉起 |

**行为特点 / 弱点**：总在空中，近战必须等它俯冲下来才能打到；俯冲路径是直线，侧移即可躲。
俯冲只结算一次接触伤害，冲空后有 0.65s 拉起，是最佳输出窗口。
受击会立即向上窜（1.3 倍速、上移 70px），近战连段容易断。
源码 bug：`hitWall` 依赖 `body.wallDir`，但飞行体从不调用 `moveBody`，该值恒为 0，撞墙拉起分支永远不会触发；俯冲会直接穿过地形（每轴避障只作用于 `_moveTowards` 的插值位置）。

### 3.5 失控哨兵 SENTRY · `sentry`

**面板**：HP 90 / 速度 0 / 伤害 16 / 体型 46×40 / 攻击距离 460 / 攻击冷却 2.2s / 仇恨 430 / XP 16 / biome city、factory / 特殊 固定炮塔、护盾正面 ×0.6、背面 ×1.5

| 瞄准锁定 | 距离 < 430 且视线通畅且在扇形内；或被打过（`aggroT > 0`）时距离 < 516 | 0.7s：红色瞄准线实时追随玩家、落点光点旋转、蜂鸣加速；玩家跑出视线或距离 > 529 立刻中断（转 0.4s 冷却） | 无伤害（纯警告） | 0.7s 满后开火 |

瞄准线是完整前摇：0.7s 内离开线段 18px 之外即可完全免伤，跑出视线也能打断。
被任何攻击打中都会立刻锁定，远程偷袭会换来一次精准还击。

**招式**

## 六、人类劫匪（3）

> 三只共用 `BanditBase`：`tryAttack()` 恒返回 false、`performAttack()` 空实现、`damage = 0`、`aggro = 0`、`attackRange = 0`、`attackCooldown = 9`。
