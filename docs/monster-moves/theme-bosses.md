## 通用规则

- 出招状态机：`chase → wind:<move>（前摇，读攻击/施法帧）→ exec → recover（0.45s）→ chase`。
- 冷却：每招独立 `cool` 秒；两招之间另有 1.1–1.5s（二阶段 0.9s）的选招间隔。
- 距离带：`range` 外不会主动出招；最大距离 ≥ 400 的远程招在贴身时仍可释放。
- 连招：收招后有 55% 概率立刻接下一招，一阶段最多 1 段追加，二阶段最多 2 段。
- 二阶段：HP ≤ 50% 时触发——移速 ×1.16、基础攻击 ×1.18、立即释放首个签名招，选招间隔缩短、签名招概率 35%→55%。
- 签名招：★ 标记的招式（每只 3 招，含 kit 首招 + 两招专属签名）在选招池里带概率优先，一阶段 35%、二阶段 55%。
- 入场：玩家进入 780 距离后激活，`intro` 1.25s 演出；未激活时只做 0.5 倍速巡游。
